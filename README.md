# Стратегический дашборд CEO — MVP

Дашборд считает 4 ключевые метрики (выручка план/факт, валовая маржа, денежный
поток, дебиторка по срокам) из трёх Excel-файлов и раскрашивает их светофором
(зелёный / жёлтый / красный) по заданным порогам.

Идея: директор не меняет свой процесс — он по-прежнему выгружает отчёты из 1С
в Excel вручную, без сводных таблиц. Единственное требование — колонки в файле
должны называться так же, как в шаблонах из `sample_data/`.

## Запуск

```bash
pip install -r requirements.txt
streamlit run app.py
```

Откроется в браузере на `http://localhost:8501`. По умолчанию используются
демо-данные из `sample_data/` (сгенерированы `generate_sample_data.py` —
условный дистрибьютор заморозки/охлаждёнки, 6 месяцев).

## Как подключить свои данные

В сайдбаре три поля загрузки — просто перетащите свои xlsx вместо демо-файлов.
Структура колонок должна совпадать с образцами:

**Продажи (`sales_plan_fact.xlsx`)**
`Месяц | Направление | План_руб | Факт_руб | Себестоимость_руб`

**ДДС (`cash_flow.xlsx`)**
`Дата | Вид_деятельности | Статья | Тип (Приток/Отток) | Сумма_руб`
`Вид_деятельности` — одно из: Операционная / Инвестиционная / Финансовая.

**Дебиторка (`receivables.xlsx`)**
`Клиент | Дата_отгрузки | Плановая_дата_оплаты | Сумма_руб`

Если в реальной выгрузке 1С колонки называются иначе — не трогайте `app.py`,
правьте только `data_pipeline.py` (функции `load_sales`, `load_cash_flow`,
`load_receivables`) — это единственное место, которое знает про структуру
входных файлов.

## Где настраиваются пороги светофора

Файл `data_pipeline.py`, словарь `THRESHOLDS` в начале файла:

- `plan_fact` — % выполнения плана (по умолчанию зелёный ≥100%, жёлтый 90–99%)
- `margin_target` — целевая валовая маржа (по умолчанию 20%)
- `ar_overdue_share` — допустимая доля просроченной дебиторки
- `opening_cash_balance` — стартовый остаток ДС (можно также задать прямо в
  интерфейсе, в сайдбаре)

## Что дальше (не реализовано в MVP)

- Метрики NPS/CAC/конверсия воронки — сознательно не включены: под них нет
  источника данных в вашей текущей выгрузке (1С без CRM). Добавляются как
  4-й Excel-файл + новая функция в `data_pipeline.py`, когда появится источник.
- Автообновление данных — сейчас файл заливается вручную через интерфейс.
  Следующий шаг — папка с автоматическим забором свежих xlsx по расписанию.
- Назначение "владельцев метрик" (Шаг 5 из ТЗ) — организационный процесс,
  вне периметра дашборда.
